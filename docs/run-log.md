### 1. 왜 ‘부가 아이디어’라고 설명했나요?

기획서 앞부분에 적힌 핵심 목적과 기본 동작을 보면, 이 앱의 본질은 “개인이 본 영화를 검색해 포스터와 함께 S~D 5단계 티어로 정리하고 관리하는 것”입니다.

# 영화 티어리스트 개발 계획서

* **가장 중요한 기능**: 영화를 드래그해서 S부터 D까지 등급별로 분류하고 관리해요.
* **가장 먼저 만들 기능**: 화면에 영화 카드가 보이고 티어에 넣을 수 있어야 하므로 기본 화면과 티어 칸을 먼저 만들어요.

## 로드맵

1단계 기본 화면 & 티어 → 2단계 설정 & 검색 → 3단계 드래그 & 배정 → 4단계 책갈피 관리 → 5단계 저장 & 불러오기 → 6단계 이미지 저장

## 단계별 실행 순서

* **1단계 | 기본 화면 & 티어**
* **할 일**: S부터 D까지 5단계 피라미드 티어 칸과 초기 영화 목록, 반응형 기본 화면을 만들어요.
* **✅ 완료 기준**: 처음 화면을 열면 S부터 D까지의 티어 칸과 초기 영화 10편 포스터 카드들이 보여요.




* **2단계 | 설정 & 검색**
* **할 일**: TMDB API 키 설정과 영화 검색, 중복 확인, 목록 추가 및 좌우 더보기 기능을 만들어요.
* **✅ 완료 기준**: 빈칸 검색 시 안내 문구가 나오고, 영화를 검색해 추가하면 목록에 카드가 보여요.




* **3단계 | 드래그 & 배정**
* **할 일**: 목록과 티어 간 드래그 이동, 등급 변경 및 삭제 메뉴 기능을 만들어요.
* **✅ 완료 기준**: 목록 카드를 S 티어에 드래그해 놓으면 S 티어 칸에 영화가 보여요.




* **4단계 | 책갈피 관리**
* **할 일**: 제목을 지정해 여러 책갈피를 만들고 각자 등급 배치를 따로 관리하는 기능을 만들어요.
* **✅ 완료 기준**: 새 책갈피를 만들고 영화를 배치하면 다른 책갈피와 구별된 등급 화면이 보여요.




* **5단계 | 저장 & 불러오기**
* **할 일**: 브라우저 자동 저장, 현재 또는 전체 페이지 JSON 파일 저장, 백업과 확인 안내가 있는 불러오기 기능을 만들어요.
* **✅ 완료 기준**: 현재 또는 전체 페이지로 저장한 뒤 불러오기에서 백업과 확인을 거치면 저장된 내용과 안내가 화면에 보여요.




* **6단계 | 이미지 저장**
* **할 일**: 티어리스트 영역을 PNG 이미지 파일로 저장하는 기능을 만들어요.
* **✅ 완료 기준**: 이미지 저장을 누르면 추가한 영화 목록을 제외한 티어리스트가 PNG 파일로 저장돼요.

## 3. 화면과 동작
### 3-1. 추가한 영화 목록

#### 위치 및 구성

검색창 아래에 추가한 영화를 가로 한 줄로 표시한다.
각 항목은 TMDB에서 가져온 포스터와 제목으로 이루어진 카드이다.

#### 동작

검색 결과에서 [목록에 추가]를 누르면 이 목록에 나타난다.
목록의 카드를 드래그해서 S / A / B / C / D 티어 행에 놓으면 해당 등급으로 배정되고, 목록에서 사라진다.
목록이 한 줄에 다 보이지 않으면 양쪽 끝에 ◀ 더보기 / 더보기 ▶ 버튼을 두고, 누를 때마다 목록을 가로로 넘긴다. 더 넘길 방향이 없으면 해당 버튼은 비활성화된다.
목록이 비어 있으면 "검색으로 영화를 추가해 보세요"라는 안내를 표시한다.

#### 티어 카드 조작

티어에 배정된 카드는 다른 티어로 드래그해서 등급을 바꿀 수 있다.
카드를 누르면 등급 변경 또는 삭제 메뉴가 열린다.

#### 예외 처리

포스터를 가져오지 못한 영화는 제목만 표시되는 기본 카드로 보여 준다.
같은 제목의 영화는 목록과 티어 어디에서도 중복 추가되지 않고, "이미 추가된 영화입니다" 안내를 표시한다.

### 3-2. 포스터 표시
포스터는 검색 결과와 목록, 티어 카드에 TMDB 이미지 서버에서 직접 불러와 표시한다.
포스터를 가져오지 못한 영화는 제목이 적힌 회색 기본 카드로 대체한다.
키를 저장하면 포스터가 없는 기본 목록 영화도 자동으로 포스터를 채운다.

#### 이미지 저장 제한
PNG 저장은 화면에 보이는 티어리스트 영역만 담는다. 추가한 영화 목록은 포함하지 않는다.
포스터는 웹 보안 정책에 따라 PNG에 빠질 수 있으며, 이 경우 제목 카드 형태로 저장될 수 있다.
이미지 저장은 인터넷 연결이 필요하다(html2canvas를 CDN에서 불러옴).

## 🎯 목적과 핵심 기능

> **목적**: 개인이 본 영화를 TMDB로 검색해 카드로 만들고, S~D 피라미드 티어에 배치·수정·삭제하며 저장/불러오기/PNG 저장과 책갈피 관리를 단일 HTML 화면으로 해내는 도구.

* **🏆 가장 중요한 기능**: **S~D 피라미드 티어 배치 및 등급 변경/삭제** — 이 앱이 단순 영화 검색기가 아니라 내가 본 영화를 등급별로 정리하는 ‘티어리스트’라는 목적을 직접 이루는 핵심이기 때문이에요.
* **🚀 가장 먼저 만들 기능**: **단일 HTML 뼈대와 추가한 영화 목록·S~D 티어 카드/드래그/메뉴 조작** — TMDB 키가 없어도 초기 영화 목록과 카드 조작·등급 이동 흐름을 먼저 띄워야 이후 검색·저장·책갈피 기능을 얹기 쉽기 때문이에요.

## 3. 화면과 동작
### 3-1. 추가한 영화 목록

#### 위치 및 구성

검색창 아래에 추가한 영화를 가로 한 줄로 표시한다.
각 항목은 TMDB에서 가져온 포스터와 제목으로 이루어진 카드이다.

#### 동작

검색 결과에서 [목록에 추가]를 누르면 이 목록에 나타난다.
목록의 카드를 드래그해서 S / A / B / C / D 티어 행에 놓으면 해당 등급으로 배정되고, 목록에서 사라진다.
목록이 한 줄에 다 보이지 않으면 양쪽 끝에 ◀ 더보기 / 더보기 ▶ 버튼을 두고, 누를 때마다 목록을 가로로 넘긴다. 더 넘길 방향이 없으면 해당 버튼은 비활성화된다.
목록이 비어 있으면 "검색으로 영화를 추가해 보세요"라는 안내를 표시한다.

#### 티어 카드 조작

티어에 배정된 카드는 다른 티어로 드래그해서 등급을 바꿀 수 있다.
카드를 누르면 등급 변경 또는 삭제 메뉴가 열린다.

#### 예외 처리

포스터를 가져오지 못한 영화는 제목만 표시되는 기본 카드로 보여 준다.
같은 제목의 영화는 목록과 티어 어디에서도 중복 추가되지 않고, "이미 추가된 영화입니다" 안내를 표시한다.

### 3-2. 포스터 표시
포스터는 검색 결과와 목록, 티어 카드에 TMDB 이미지 서버에서 직접 불러와 표시한다.
포스터를 가져오지 못한 영화는 제목이 적힌 회색 기본 카드로 대체한다.
키를 저장하면 포스터가 없는 기본 목록 영화도 자동으로 포스터를 채운다.

#### 이미지 저장 제한
PNG 저장은 화면에 보이는 티어리스트 영역만 담는다. 추가한 영화 목록은 포함하지 않는다.
포스터는 웹 보안 정책에 따라 PNG에 빠질 수 있으며, 이 경우 제목 카드 형태로 저장될 수 있다.
이미지 저장은 인터넷 연결이 필요하다(html2canvas를 CDN에서 불러옴).
