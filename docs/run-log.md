#### 3단계 이미지 오타 재검증

**검증 대상**은 영화 티어리스트 개발 계획서 이미지의 3단계 ‘드래그 및 등급 조작’ 카드다. 아래 인용은 사용자가 공유한 Gemini 대화에서 발췌했다.

| 순서 | 실제 대화에서 확인한 내용 |
|---|---|
| 첫 답변 | Gemini는 완료 기준 두 번째 줄의 오타를 `카드를 클릭해 [삭제]를 누르면 하면 화면에서 사라져요.` → `카드를 클릭해 [삭제]를 누르면 화면에서 사라져요.`로 짚었다. |
| 후속 확인 | 사용자가 공유한 후속 답변에서도 Gemini는 `[삭제]` 다음을 `를 누르면 하면 화면에서 사라져요.`라고 인용했다. |
| 재검증 질문 | “이번에는 이미지의 3단계 ‘드래그 및 등급 조작’을 확인해줘. ‘할 일’과 ‘완료 기준’에서 오타가 보이면, 어느 줄인지 짚고 이미지에 적힌 표현 → 고친 표현 순서로 써줘. 정확히 읽히지 않는 글자는 추측하지 말고 알려줘” |
| 재검증 답변 | Gemini는 “오타: 보이지 않아요.”, “정확히 읽히지 않는 글자: 없어요.”라고 답했다. 완료 기준의 끝을 `카드를 클릭해 [삭제]를 누르면 화면에서 사라져요.`라고 옮겼다. |
| 사용자 최종 판정 | “아니지완료기준에서 하면 화면에서 를 못찾았으니까 환각이야” |

**재검증 결과 · Fail(환각).** 내가 확인한 이미지에는 ‘누르면 **하면** 화면에서’라고 적혀 있었다. Gemini는 처음에는 ‘하면’을 찾아냈지만, 재검증에서는 그 단어를 빠뜨린 문장을 이미지 원문으로 제시하고 오타가 없다고 단정했다. 이 판정은 마지막 재검증 답변에 적용한다.

#### Few-shot 이미지 확인

- **제목 오타** · 이미지 제목은 ‘영화 회 티어리스트 개발 계획서’로, 요청한 제목 ‘영화 티어리스트 개발 계획서’에 ‘회’가 한 글자 더 들어갔다.
- **책갈피 누락** · 로드맵과 다섯 단계 카드에 책갈피가 없다. 기획서 완성 기준 9번의 여러 책갈피 생성·책갈피별 독립 배치와 10번의 현재 페이지 또는 전체 페이지 저장 선택이 모두 빠졌다. 4단계에는 자동 저장과 파일 저장·불러오기만 나온다.
- **확인 질문 없이 제작** · 나는 제미나이가 먼저 묻지 않고 이미지를 바로 만들었다고 기록했다. 단계를 한 장에 담기 어려울 때에는 기능과 완료 기준을 유지하면서 관련 단계를 묶어도 되는지 묻도록 예시 2에 적었다. 책갈피가 빠진 이유는 확인되지 않았다.
