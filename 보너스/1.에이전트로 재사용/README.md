# 보너스 1. 에이전트로 재사용

저장 경로는 `보너스/1.에이전트로 재사용/`입니다. 기획서를 주면 ‘개발 순서 길잡이’가 가장 중요한 기능과 먼저 만들 기능을 구분하고, 단계별 할 일과 완료 기준을 기본 1장의 인포그래픽으로 정리합니다. 내용이 많으면 최대 2장으로 나눕니다.

## 과제 요구사항

- 최종 프롬프트를 커스텀 인스트럭션이나 에이전트 기능으로 재사용 가능한 형태로 배포한다.
  - 요구사항 4에서 완성한 시스템 프롬프트를 그대로 사용한다.
  - 배포한 화면과 배포한 것을 다시 불러 쓴 결과를 함께 남긴다.

## 등록하고 다시 쓰는 방법

1. ChatGPT 스킬 편집기에서 이름을 **개발 순서 길잡이**로 정합니다. [개발순서길잡이스킬.md의 ‘등록할 시스템 프롬프트’](개발순서길잡이스킬.md#등록할-시스템-프롬프트)에서 지침을 복사해 저장합니다. [설계 문서 4-2절 · 시스템 프롬프트 v2](../../docs/system-design.md#5-2-시스템-프롬프트-v2--few-shot-텍스트-생성)
2. 새 대화에서 저장한 스킬을 선택합니다. 영화 티어리스트로 재실행할 때는 기획서와 [장보기 체크리스트 예시 이미지](../../docs/assets/grocery-checklist-example.png)를 첨부하고 **“개발 순서 길잡이로 첨부한 기획서의 개발 계획서를 만들어줘.”**라고 요청합니다. 다른 기획서를 넣을 때는 [개발순서길잡이스킬.md의 ‘새 기획서를 넣을 때 쓰는 입력 템플릿’](개발순서길잡이스킬.md#새-기획서를-넣을-때-쓰는-입력-템플릿)에서 중괄호 세 곳을 채웁니다.
3. 저장 화면을 캡처하고, 새 대화에서 받은 결과와 함께 [검증기록](검증기록.md)에 남깁니다.
