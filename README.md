# 비주얼 개발 플래너

‘개발 순서 길잡이’에 기획서를 넣으면, 어떤 기능이 가장 중요하고 무엇부터 만들어야 하는지 1~2장의 인포그래픽 개발 계획서로 보여 줍니다. 각 단계에는 할 일, 만들고 나면 생기는 결과물, 다음 단계로 넘어가기 전에 직접 확인할 완료 기준이 담깁니다. 완성된 계획서는 마크다운 파일로 내려받을 수 있습니다.

 ‘AI Agent에게 일 제대로 시키는 법 배우기’에서 이 도우미의 프롬프트를 설계하고, 영화 티어리스트 기획서로 시험했습니다.

## 산출물 읽는 순서

| 순서 | 파일명 | 한 줄 소개 |
|---|---|---|
| 1 | [model-comparison.md](docs/model-comparison.md) | 같은 영화 티어리스트 기획서로 세 모델의 응답을 비교하고 Gemini 자동 모드를 선택한 이유를 정리했습니다. |
| 2 | [system-design.md](docs/system-design.md) | ‘개발 순서 길잡이’의 역할과 프롬프트를 설계하고, 예시를 넣었을 때 개발 계획서가 어떻게 달라졌는지 비교했습니다. |
| 3 | [run-log.md](docs/run-log.md) | 실제로 주고받은 질문과 답변을 작업별로 모아 같은 요청을 다시 했을 때 나온 결과까지 기록했습니다. |
| 4 | [unresolved.md](docs/unresolved.md) | 영화 티어리스트 인포그래픽에서 끝내 고치지 못한 부분과 수정을 위해 시도한 방법을 기록했습니다. |

## 모델 비교 자료

세 모델에 영화 티어리스트 ‘미션 1-4’ 기획서와 같은 요청을 입력했습니다. 아래에서 기획서와 각 모델이 작성한 개발 계획서를 열어 볼 수 있습니다.

| 구분 | 파일명 | 한 줄 소개 |
|---|---|---|
| 공통 입력 | [영화티어리스트 기획서 자료.md](<영화티어리스트 기획서 자료.md>) | 영화 티어리스트의 목적·기능·완성 기준이 담긴 입력 원문입니다. |
| 모델 A 결과 | [클로드개발계획서v1.md](클로드개발계획서v1.md) | Claude 쏘넷 5.5를 ‘중간’으로 설정해 받은 개발 계획서 원문입니다. |

## 기록 기준

- 실제 사용한 프롬프트, 모델 응답과 직접 작성한 평가 원문을 보존합니다.
- AI가 제안한 점수 초안은 직접 작성한 평가와 구분합니다.
- 아직 실행하지 않았거나 확인하지 못한 항목은 비워 둡니다.
- 개인정보, API 키, 비밀번호와 계정 이메일은 공개 기록에 포함하지 않습니다.
