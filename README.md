## 프로젝트 소개

‘개발 순서 길잡이’에 기획서를 넣으면, 어떤 기능이 가장 중요하고 무엇부터 만들어야 하는지 1~2장의 인포그래픽 개발 계획서로 보여 줍니다. 각 단계에는 할 일, 만들고 나면 생기는 결과물, 다음 단계로 넘어가기 전에 직접 확인할 완료 기준이 담깁니다. 완성된 계획서는 마크다운 파일로 내려받을 수 있습니다.

 ‘AI Agent에게 일 제대로 시키는 법 배우기’에서 이 도우미의 프롬프트를 설계하고, 영화 티어리스트 기획서로 시험했습니다.

## 기록 기준

- 실제 사용한 프롬프트, 모델 응답과 직접 작성한 평가 원문을 보존합니다.
- AI가 제안한 점수 초안은 직접 작성한 평가와 구분합니다.
- 아직 실행하지 않았거나 확인하지 못한 항목은 비워 둡니다.
- 개인정보, API 키, 비밀번호와 계정 이메일은 공개 기록에 포함하지 않습니다.
