## 1. 핵심 기능 우선순위

| 우선순위 | 기능 | 선정 이유 |
| :--- | :--- | :--- |
| **1순위 (출발점)** | 피라미드 화면 & 카드 이동 | API나 저장 없이도 티어리스트의 핵심 재미와 동작 틀을 가장 먼저 검증할 수 있습니다. |
| **2순위 (핵심 가치)** | TMDB 영화 검색 & 카드 생성 | 내가 본 영화를 포스터와 함께 직접 찾아 목록에 넣어야 나만의 티어리스트가 됩니다. |
| **3순위 (데이터 유지)** | 자동 저장 · 파일 백업 · PNG 저장 | 분류한 등급이 사라지지 않게 보관하고, 완성된 표를 이미지로 간직·공유하기 위함입니다. |
| **4순위 (안정화)** | 입력·오류 안내 & 모바일 반응형 | 빈칸·중복·키 오류 시 당황하지 않게 안내하고, 좁은 창에서도 화면이 잘리지 않게 합니다. |
| **5순위 (최종 필수)** | 여러 책갈피 & 저장 범위 선택 | 주제별로 티어리스트를 독립 관리하고, 현재 또는 전체 페이지를 골라 저장해 기획서를 최종 완성합니다. |

## 3. 단계별 실행 가이드 (가로형 카드)

### 🧱 1단계 카드
| 단계 · 제목 | 할 일 & 결과물 | ✅ 완료 기준 (직접 해보고 통과) |
| :--- | :--- | :--- |
| **1단계**<br>**영화 카드 옮기기** | **할 일**<br>- [ ] 노란색 그라데이션 S~D 피라미드와 상단 가로 목록 틀 만들기<br>- [ ] 초기 영화 10편 회색 기본 카드 띄우기 & 양쪽 `◀ 더보기 / 더보기 ▶` 구현<br>- [ ] 목록→티어, 티어→티어 드래그 이동 및 카드 클릭 시 등급 변경·삭제 메뉴 연결<br><br>**결과물:** 브라우저에서 열리고 카드가 자유롭게 움직이는 `index.html` 1장 | - [ ] 초기 영화 10편 카드를 S~D 칸으로 끌어다 놓으면 목록에서 사라지고 해당 칸에 들어간다.<br>- [ ] 티어에 넣은 카드를 다른 칸으로 옮기거나, 클릭해 등급 변경·삭제할 수 있다.<br>- [ ] 목록이 길 때 `◀ 더보기 / 더보기 ▶` 버튼으로 가로 이동이 되고, 비어 있으면 안내 문구가 뜬다. |

### 🔍 2단계 카드
| 단계 · 제목 | 할 일 & 결과물 | ✅ 완료 기준 (직접 해보고 통과) |
| :--- | :--- | :--- |
| **2단계**<br>**영화 검색해 넣기** | **할 일**<br>- [ ] ⚙️ 설정 창에서 TMDB API 키(v3) 입력 후 브라우저(`localStorage`)에 저장하기<br>- [ ] 영화 제목 검색 시 TMDB API로 포스터·제목 가져와 `[목록에 추가]` 연결<br>- [ ] 키 저장 시 기존 초기 영화 10편 카드에도 포스터 자동 채우기<br><br>**결과물:** 실제 영화 포스터가 검색되고 목록에 추가되는 화면 | - [ ] ⚙️ 설정에 v3 API 키를 넣고 저장하면 초기 영화 10편 카드에 포스터가 채워진다.<br>- [ ] 영화 제목을 검색해 `[목록에 추가]`를 누르면 포스터와 제목이 붙은 카드가 목록에 생긴다.<br>- [ ] 포스터가 없는 영화도 깨지지 않고 제목이 적힌 회색 기본 카드로 표시된다. |

### 💾 3단계 카드
| 단계 · 제목 | 할 일 & 결과물 | ✅ 완료 기준 (직접 해보고 통과) |
| :--- | :--- | :--- |
| **3단계**<br>**등급 저장·캡처** | **할 일**<br>- [ ] 카드 배치 변경 시 `localStorage` 자동 저장 (API 키는 파일에 미포함)<br>- [ ] JSON `[파일저장]` 및 3단계 안전장치(백업 여부→자동 백업→교체 확인) `[불러오기]` 구현<br>- [ ] `html2canvas` CDN을 연결해 티어 영역만 PNG `[이미지저장]` 구현<br><br>**결과물:** 새로고침·파일 복원·PNG 이미지 다운로드가 되는 티어리스트 | - [ ] 영화를 S~D에 배치한 뒤 브라우저를 새로고침해도 등급과 위치가 그대로 남아 있다.<br>- [ ] `[파일저장]`으로 JSON을 내려받은 뒤 화면을 비우고 `[불러오기]`를 실행하면 안전장치 안내를 거쳐 복원된다.<br>- [ ] `[이미지저장]`을 누르면 상단 목록은 빠지고 S~D 티어리스트 영역만 담긴 PNG 파일이 저장된다. |

### 🛡️ 4단계 카드
| 단계 · 제목 | 할 일 & 결과물 | ✅ 완료 기준 (직접 해보고 통과) |
| :--- | :--- | :--- |
| **4단계**<br>**오류·좁은창 막기** | **할 일**<br>- [ ] 빈칸 검색(`영화 제목을 입력해주세요`), 중복 추가(`이미 추가된 영화입니다`) 차단<br>- [ ] API 키 미입력·401 인증 실패(v3 안내)·네트워크 오류 안내 문구 표시<br>- [ ] 모바일·좁은 브라우저 폭에서도 오른쪽이 잘리지 않도록 반응형 CSS 적용<br><br>**결과물:** 잘못된 입력을 막아주고 모바일에서도 깨지지 않는 안정화된 화면 | - [ ] 빈칸이나 공백만 넣고 검색하거나 이미 있는 영화를 다시 추가하면 카드 대신 안내 문구가 뜬다.<br>- [ ] API 키를 비우거나 틀린 키를 넣으면 검색창 아래에 원인 안내 문구가 표시된다.<br>- [ ] 브라우저 창 너비를 모바일 크기처럼 좁혀도 오른쪽 화면이 잘리지 않고 모든 기능을 쓸 수 있다. |

### 📑 5단계 카드 (최종 완성 필수)
| 단계 · 제목 | 할 일 & 결과물 | ✅ 완료 기준 (직접 해보고 통과) |
| :--- | :--- | :--- |
| **5단계**<br>**책갈피 나눠 쓰기** | **할 일**<br>- [ ] 제목을 지정해 여러 개의 책갈피(페이지)를 생성·전환하는 탭/목록 만들기<br>- [ ] 각 책갈피마다 영화 목록과 S~D 등급 배치를 독립적으로 저장·관리하기<br>- [ ] 파일 저장 실행 시 **현재 페이지** 또는 **전체 페이지** 저장 선택 기능 추가<br><br>**결과물:** 여러 주제별 티어리스트를 나눠 관리하고 선택 저장하는 최종 완성본 | - [ ] ① 책갈피 A와 B 두 개를 만든 뒤, A에서 영화 등급을 바꿔도 B의 영화 배치는 그대로 유지되는지 확인한다.<br>- [ ] ② 파일 저장을 누르면 **현재 페이지**만 저장할지 **전체 페이지**를 저장할지 선택할 수 있고, 선택한 범위대로 저장·복원되는지 확인한다. |
